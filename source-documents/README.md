# source-documents/

This folder holds the **editable originals** of every document in `submission/`. Each file in here was converted to PDF and placed in the matching folder under `submission/` for grading.

If you want to edit any of the deliverables, edit the file here and re-export.

---

## Folder Map

| Folder | What's here |
|--------|-------------|
| `pitch/` | The two PowerPoint pitch decks (`Autotraq Slide Presentation.pptx`, `AutoTraQ_Feature_Showcase.pptx`), the feature list markdown, and the assets used by the feature showcase deck. |
| `project-plan/` | Original CS 490 capstone project plan (Word). |
| `per-module-writeups/` | Per-subsystem narrative write-ups: frontend, backend, database, charts (Word). |
| `cheatsheets/` | Per-teammate cheat sheets for the demo (Markdown). |
| `testing/plans/` | Per-teammate manual QA checklists (Markdown). |
| `testing/reports/` | Completed test reports — Gus's backend report (Word), Dean's full QA workbook (Excel), and the Parts-section PDF extract. |
| `development-process/` | Production-readiness analysis, dev incident reports, and the phase tracker (Word + Markdown). |
| `api-reference/` | Full REST API reference (Markdown). |
| `client-onboarding/` | Client onboarding guide for introducing AutoTraQ to a new client (Markdown). |
| `tools/` | The Python script that generated `pitch/AutoTraQ_Feature_Showcase.pptx`. Re-runnable; reads its assets from `pitch/feature-showcase-assets/`. |

---

## Why this folder exists

The professor only needs `submission/`. This folder is for the **team** — it's the editable source for every PDF the professor will see, kept alongside the project so future updates don't require regenerating from scratch.
